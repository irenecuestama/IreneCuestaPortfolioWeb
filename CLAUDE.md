# CLAUDE.md

Proyecto: portfolio web de Irene Cuesta (marketing digital). **Lee `README.md` entero antes de hacer cualquier cambio**: contiene el contexto, la dirección de diseño, todos los datos reales de Irene, los pendientes y las reglas de trabajo.

Resumen mínimo:
- La web elegida es `01-minimal/` (HTML/CSS/JS sin compilación). Las carpetas `02`–`04` son plantillas descartadas.
- Vista previa: `python -m http.server 5500` en esta carpeta → http://localhost:5500/01-minimal/
- No inventes datos de Irene (cifras, años, clientes, herramientas): usa solo los del README o pregúntale.
- Colores siempre mediante las variables de `01-minimal/styles.css`. El naranja es el color principal; el azul, solo para detalles pequeños.
- Cada texto visible nuevo necesita su traducción ES/EN en el objeto `dict` de `01-minimal/script.js`.
- Al terminar cambios importantes, actualiza `README.md`.
